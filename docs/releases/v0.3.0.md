# AI Workstation Topic Intelligence v0.3.0

> Historical release note. For current installation paths, see the
> [installation guide](../install.md).

Topic Intelligence helps creators, researchers, and editors find current topics worth researching and turn one into an actionable content brief.

## Download

Download `topic-intelligence-0.3.0.zip` from the GitHub Release assets.

```text
SHA256  935bab465811a3efabd50ee46c3166c702ad719d19fd66ade718d871b69b066e
```

Use the accompanying `SHA256SUMS` or `release-manifest.json` to verify the download.

## What it supports

- shortlist current topics worth researching;
- brief a supplied current Radar topic;
- select one topic and continue into a brief for the same topic.

## Install

- **Codex:** use the Release archive or repository installer documented in the
  [current installation guide](../install.md).
- **Other Agent Skills hosts:** import the ZIP or Skill directory according to
  the host's documented installation workflow.

## Try it

```text
Choose one current AI topic for a two-to-three-minute explainer, then turn it into a research-ready content brief. Include the audience payoff, strongest angle, opening, narrative structure, must_verify, avoid_claims, and suggested visuals.
```

## Evidence and privacy

- Current claims require current Radar evidence.
- Incomplete or older source coverage must be disclosed.
- Radar does not measure actual audience size, topic saturation, or future reach.
- The public Skill uses read-only Radar access and requires no AI Workstation API key.
- Do not share credentials, private conversations, or client data in public issues.
