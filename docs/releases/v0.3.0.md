# AI Workstation Topic Intelligence v0.3.0

AI Workstation Topic Intelligence is one public Skill for creators, researchers, and editors. It reads current public signals from the AI Workstation Global Topic Radar and uses the user’s current host model to support three workflows:

1. shortlist current topics worth researching;
2. turn a supplied current Radar topic into a research-ready content brief;
3. select one current topic and continue directly into a brief for the same finalist.

## Download

The public Skill does not require an AI Workstation API key and does not consume AI Workstation server-side LLM quota. Radar provides public evidence; the user’s current ChatGPT, Codex, or other compatible host model performs the editorial reasoning.

## Install

- **Codex:** install the ZIP as the `topic-intelligence` Skill, or use the repository installer documented in the [README](https://github.com/zxhwolfe-dev/aiworkstation-topic-intelligence#readme).
- **ChatGPT:** use a workspace that supports Personal Skills and upload the ZIP. Product availability depends on the current workspace and plan. Follow the [ChatGPT installation guide](https://github.com/zxhwolfe-dev/aiworkstation-topic-intelligence/blob/main/docs/chatgpt-install.md).
- **Compatible Agent Skills hosts:** import the ZIP or Skill directory according to the host’s instructions; the host must run the bundled Python helper and allow public Radar HTTP access.

## Try it

Topic shortlist:

```text
Which AI topics are worth researching or covering today? Check Radar freshness first, then give me the three strongest candidates. Do not write a full brief.
```

Supplied topic to brief:

```text
Turn this current Radar topic into a research-ready content brief. Only query history if movement evidence is genuinely needed, and do not select a different topic.
```

Selection followed by brief:

```text
Choose one current AI topic that is best suited to a two-to-three-minute explainer, then turn it directly into a research-ready content brief. Include the audience payoff, strongest angle, opening three seconds, narrative structure, must_verify, avoid_claims, and suggested visuals.
```

On **2026-08-12**, the final official Release ZIP completed a real post-release ChatGPT Web smoke using natural user prompts:

Full record: [ChatGPT Web v0.3.0 three-mode smoke result](https://github.com/zxhwolfe-dev/aiworkstation-topic-intelligence/blob/main/docs/chatgpt-v0.3.0-smoke-result-2026-08-12.md)

## Evidence and limitations

- Radar facts, host editorial judgment, and unknowns remain visibly separate.
- Radar does not measure actual audience size, topic saturation, or future virality.
- `stale` or `partial` responses must be disclosed.
- The public helper exposes only read-only `feed`, `sources`, and `history` operations. It does not expose anonymous server-side `/insight` model execution.
- The v0.3.0 release also carries a complete seven-case live Codex Host Eval, semantic grading, manual review, and persistent release evidence.
- This post-release documentation update does not alter the v0.3.0 ZIP, checksum, manifest, `SHA256SUMS`, tag, or immutable release evidence.
