# AI Workstation Topic Intelligence v0.3.1

Topic Intelligence helps creators, researchers, and editors use current Radar
signals to choose research opportunities and build a brief for one exact topic.

## What changed

- Normal Radar reads are pinned to the official AI Workstation origin.
- Saved topic cards older than the current freshness boundary are no longer
  presented as evidence that a topic is accelerating now.
- Radar observations, host analysis, recommendations, and claims requiring
  verification are separated more clearly.
- Triggering is narrower for ordinary news lookup, rewriting, translation,
  summarization, generic title generation, and completed supplied material.
- The default shortlist request is limited to 12 candidates.

## Install

Download the release archive and place its `topic-intelligence/` directory in
the Skill location documented by Codex or another compatible Agent Skills host.
For a repository checkout, use the included Codex installer.

The public Skill uses read-only Radar access, requires no AI Workstation API key,
and does not predict audience size, content saturation, or future reach.
