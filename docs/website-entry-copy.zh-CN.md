# aiworkstation.cn 产品入口文案（M3）

这份文案用于把 Topic Intelligence 作为用户产品介绍，而不是把 Skill 架构直接暴露给普通用户。

## 首屏

### 主标题

**今天什么 AI 题材值得做？**

### 副标题

不是再给你一份新闻列表。

从全球热点信号里，先检查数据新鲜度和来源覆盖，再帮你找出正在升温、值得继续研究的题材；选中后还能直接生成研究就绪的内容简报。

### 唯一 CTA

**看看今天值得研究的题材**

### 信任说明

当前结论基于 AI Workstation Global Topic Radar 的实时数据。实时数据不可用时不会用模型记忆或本地旧数据冒充“当前热点”。

## 第二屏：它解决什么问题

### 你可能遇到的是这些问题

- 每天 AI 新闻太多，不知道哪些值得继续看；
- 海外已经出现信号，但不知道是否值得中文内容提前跟；
- 看到了热点，却不知道从什么角度做才有价值；
- AI 很会写，但容易把推测写成事实；
- 做完选题判断后，还要重新整理核验项、素材和研究问题。

### Topic Intelligence 做的事情

**先选对题，再把题研究清楚。**

它把流程拆成两步：

1. 找机会：从当前 Radar 信号中比较、排序、判断值得研究的题材；
2. 做简报：把一个当前 Topic 转成角度、受众收益、前三秒、研究问题、必须核验事实和不能乱说的内容。

## 一个入口，三种自动模式

官网只提供一个 Topic Intelligence 入口。用户不需要先理解 Skill 名称，也不需要在页面上选择模式；直接描述目标，Skill 会自动选择最小工作流。

### 模式 A：今天做什么

标题：

**今天有哪些 AI 题材值得关注？**

说明：

适合每天快速扫描。默认先告诉你 Radar 是否足够新，再给少量高优先级候选，而不是几十条新闻。

示例问题：

> 今天有哪些 AI 题材值得我继续研究或做内容？先检查数据新鲜度，再给我最值得看的 3 个。

### 模式 B：海外有什么早期机会

标题：

**海外正在升温、中文区可能还没充分覆盖的是什么？**

说明：

比较不同平台/地区信号。没有直接证据证明“中文区没做烂”时，会明确标记为未知或假设，不把猜测包装成数据。

示例问题：

> 海外现在有哪些科技话题正在升温、可能值得中文内容创作者提前研究？

### 模式 C：把热点变成可执行简报

标题：

**选中了热点，下一步怎么做？**

说明：

把当前 Topic 转成研究/制作可以直接接手的内容简报，包括角度、受众收益、叙事结构、素材需求、必须核验和避免声称的内容。

示例问题：

> 从当前 AI 热点里挑一个适合 2–3 分钟解释型内容的题材，给我最强角度、前三秒、必须核验的事实和素材建议。

## 证据边界说明

### 事实、分析和建议分开

页面不应把所有内容混成一个“AI 判断”。建议明确区分：

- **Radar 事实**：实时接口返回的 Topic、时间、来源、阶段、机会分、趋势和 evidence；
- **分析**：对这些信号可能意味着什么的解释；
- **建议**：是否值得继续研究、适合什么内容形式；
- **未知**：当前数据并没有证明的事情；
- **风险**：stale、partial、来源缺失、单一来源、需要进一步验证的断言。

## 面向普通用户的定位句

推荐默认使用：

> **一个帮你从全球实时热点信号里找“值得研究的题”，再把它变成可执行内容简报的 AI 选题助手。**

不要把首页主定位写成：

> Agent Skill / MCP / Topic Radar API orchestration

这些属于开发者说明，不是普通用户价值。

## ChatGPT / Codex 分流

### 普通用户

唯一入口 CTA：

**获取 Topic Intelligence**

入口打开官方 GitHub Release；用户只需获取一个 `topic-intelligence` 安装包，
不需要理解或分别安装 Creator/Brief 两个旧 Skill。

### Codex / 开发者

从同一个 GitHub Release 入口获取唯一 `topic-intelligence` 安装包；页面不再拆分 Creator/Brief 两个安装入口。

### 符合条件的 ChatGPT 工作区用户

提供：

**在 ChatGPT 中安装 Skill**

并明确：当前 ChatGPT Personal Skills 的可用性和工作区权限由 OpenAI 产品计划决定，不能承诺所有 ChatGPT 套餐均可安装。

## 首页不应该承诺的内容

避免：

- “提前发现下一个爆款”；
- “保证抓住热点”；
- “判断中文区是否已经做烂”；
- “预测什么一定会火”；
- “全网实时无遗漏”。

可以说：

- “发现值得继续研究的当前信号”；
- “比较早期机会与多来源信号”；
- “把跨市场传播当作需要验证的假设”；
- “在数据不足时明确告诉你不知道”。

## M3 首页实验建议

首轮只测试两个变量，不要一次改太多：

**今天什么 AI 题材值得做？**

### Hero B

观察：

- 首屏 CTA 点击率；
- 用户是否实际发起今日扫描；
- 扫描后是否点进某个候选；
- 是否继续生成内容简报；
- 第二天是否再次回来扫描。
