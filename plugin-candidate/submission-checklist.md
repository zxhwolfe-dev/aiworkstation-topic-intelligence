# Public Submission Checklist

## Prepared in this repository

- skills-only Plugin manifest;
- one bundled `topic-intelligence` Skill;
- name, short description, long description, category, website, support, privacy, and terms URLs;
- three starter prompts;
- five positive and three negative submission test cases;
- public read-only data and no-server-LLM boundary;
- Apache-2.0 license and public source repository;
- local Plugin validation and Skill runtime synchronization.
- production logo/icon and one product screenshot;
- release notes and intended country/region availability for portal entry.

## Publisher actions in the current OpenAI Platform UI

These steps cannot be completed by repository automation and must be rechecked against the current submission portal:

1. complete any developer-identity verification shown by the current portal;
2. select the publishing organization;
3. confirm the submitter has Apps Management write permission;
4. create a skills-only submission and upload the validated candidate bundle;
5. verify every listing field, logo, category, supported country/region, release
   notes, support URL, privacy URL, and terms URL;
6. enter or import the five positive and three negative cases if requested;
7. submit for review;
8. after approval, perform a final listing and install smoke before Publish.

Do not add MCP or Premium Insight merely to satisfy a listing field.
