# Public Submission Checklist

## Prepared in this repository

- skills-only Plugin manifest;
- one bundled `topic-intelligence` Skill;
- name, short description, long description, category, website, support, privacy, and terms URLs;
- three starter prompts;
- five positive and three negative submission test cases;
- public read-only data and no-server-LLM boundary;
- Apache-2.0 license and public source repository;
- local Plugin validation and Skill runtime synchronization.

## Publisher actions in the current OpenAI Platform UI

These steps cannot be completed by repository automation and must be rechecked against the current submission portal:

1. select the publishing organization;
2. complete the available developer or business identity verification for the `AI Workstation` publisher name;
3. confirm the submitter has the required plugin/app management permission;
4. create a skills-only submission and upload the validated candidate bundle;
5. verify every listing field, logo requirement, category, supported country/region, support URL, privacy URL, and terms URL shown by the portal;
6. enter or import the five positive and three negative cases if the portal requests them;
7. submit for review;
8. after approval, perform a final listing and install smoke before choosing Publish.

Do not claim directory availability until the listing is approved and publicly visible. Do not add MCP or Premium Insight merely to satisfy a listing field.
